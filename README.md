# 简单传送（TP）模组说明
当你和朋友相隔千里时，有没有想过使用 `tp` 命令？<br>
但是这通常需要作弊权限，可能会让你担心朋友在游戏中作弊。<br>
本模组专为最简单的传送功能而设计，不需要对方同意。<br>
此外，还增加了 `back` 命令，可以在死亡或传送后使用。<br>
---
## 命令说明
- `/tpa A`<br>
  将执行者传送到玩家 **A** 的位置。<br>
- `/tpa A B`<br>
  将玩家 **A** 传送到玩家 **B** 的位置。<br>
- `/back`<br>
  将执行者传送回记录的位置。<br>
> 注意：当玩家死亡或使用 `/tpa` 命令时，他们当前的位置会被记录。
