# 简单传送（TP）模组说明
当你和朋友相隔千里时，有没有想过使用 `tp` 命令？  
但是这通常需要作弊权限，可能会让你担心朋友在游戏中作弊。  
本模组专为简单的传送功能设计，无需复杂确认逻辑，并带有自动记录功能。
## 命令说明
1. 传送指令
- `/tpa A`
  将执行者传送到玩家 **A** 的位置。
- `/tpa A B`
  将玩家 **A** 传送到玩家 **B** 的位置。
2. 返回指令
- `/back`
  将执行者传送回传送前的位置。
- `/back death`
  将执行者传送回死亡位置
3. 快速救援
- 通过快捷按键(默认左Alt键)触发
- 在公屏发送求救信息：一支穿云箭，千军万马来相见！
- 所有玩家都会收到原版烟花发射的声音作为提示
- 其他玩家点击求救信息，即可传送进行救援
- 默认30s冷却
- `/assist A` 救援功能指令版，将执行者传送到玩家 **A** 的位置

> Tip：返回位置 与 死亡位置 属于两个独立的数据。存储在存档中，可反复返回。
